# Data Projects – Proyectos de Ciencia de Datos

Este repositorio agrupa varios proyectos de Machine Learning realizados con Python y Jupyter Notebook.

## Contenido

- Clasificación (KNN, Decision Trees, Random Forest)
- Regresión (Lineal, Polinómica)
- Agrupamiento (K-Means, DBSCAN)
- Q-Learning y SARSA (Aprendizaje por refuerzo)

## Tecnologías

- Python
- Scikit-learn
- Matplotlib / Seaborn
- Pandas, Numpy

## Cómo usar

1. Instala los paquetes requeridos con `pip install -r requirements.txt`.
2. Abre los notebooks y sigue los pasos para entrenar modelos y visualizar resultados.

Cada notebook incluye comentarios para entender el proceso de principio a fin.
